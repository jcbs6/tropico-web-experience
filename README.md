# Trópico Restobar Website

A modern restaurant website for Trópico Restobar, located in Playa de San Juan, Alicante.

## Features

- Responsive design
- Online reservation system
- Menu showcase
- Contact information
- Social media integration

## Getting Started

This project is built with Vite, React, and TypeScript.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
